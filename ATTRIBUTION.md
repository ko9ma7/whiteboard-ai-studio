## v5 architecture note

The v5 Blueprint-first compiler is an independent implementation. It adopts the general idea of an HTML composition as a declarative timing/track source from HyperFrames, and the Ink → Color → Gaze / grid-skeleton / contour-brush concepts from the public whiteboard animation skills. It does not copy their rendering engines verbatim.

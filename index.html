Claude Code는 어디에 쓰나?

Claude Code는 브라우저에서 직접 호출할 영상 생성 API가 아니라 개발 환경에서 저장소를 읽고 수정하는 코딩 에이전트입니다. 이 웹서비스 안의 “Claude 연결”은 Anthropic Claude API를 사용하고, Claude Code는 이 프로젝트 기능 추가·버그 수정·Git 커밋 같은 개발 작업에 사용하면 됩니다.

화이트보드 프롬프트 예시

16:9 educational whiteboard illustration on warm cream paper. Clean black hand-drawn ink lines, restrained flat accent colors, one clear focal subject, generous negative space, no decorative clutter, no captions or labels. Show the concept visually so individual regions can be revealed in narration order. Consistent character design and line weight across scenes.

인포그래픽 프롬프트 예시

Create a clean 16:9 explanatory infographic with one dominant visual hierarchy. Use 3–5 large semantic groups, simple arrows only when relationships need them, high contrast, minimal text, consistent icon language, and enough spacing that each group can be animated separately.

API 없이 작업

SRT 프롬프트와 장면 프롬프트를 복사해서 ChatGPT, Gemini, Claude, Grok 웹에서 실행한 뒤 결과를 다시 붙여넣으면 됩니다. 이미지도 외부 웹에서 생성한 파일을 “외부 생성 이미지 불러오기”로 넣으면 이후 플레이 과정은 동일합니다.

API를 연결하면

SRT 정리, 프롬프트 개선, 이미지 생성, OpenAI 음성 전사를 웹 안에서 실행할 수 있습니다. 키는 Worker Secret에만 두고 Pages에는 저장하지 않습니다.
